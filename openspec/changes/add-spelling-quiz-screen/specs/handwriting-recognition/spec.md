# Spec Delta

## Purpose

指で書いた英単語を端末内で文字として認識できるように、手書き入力欄・英語認識モデルの準備・認識処理の振る舞いを定める。

## ADDED Requirements

### Requirement: 指で手書きできる入力欄
手書き入力欄は、指でなぞった軌跡を線として描画し、各点の座標と時刻をストロークとして記録しなければならない（SHALL）。指を離すたびに1本のストロークが確定する。

#### Scenario: なぞった線が表示される
- **WHEN** 入力欄を指でなぞる
- **THEN** なぞった軌跡が線として表示される

#### Scenario: 複数のストロークを書く
- **WHEN** 指を離してから再び入力欄をなぞる
- **THEN** 前の線は残ったまま、新しい線が追加で表示される

### Requirement: ストロークを消す
「消す」を押すと、入力欄のストロークをすべて消去しなければならない（SHALL）。

#### Scenario: 入力を消去する
- **GIVEN** 入力欄に線が書かれている
- **WHEN** 「消す」を押す
- **THEN** 入力欄が空になる

### Requirement: 端末内で英語として認識する
手書きの認識は英語（en-US）モデルを使って端末内で行わなければならない（SHALL）。認識時には入力欄の幅と高さを書き込み領域として渡し、候補を確からしい順に返す。

#### Scenario: 書いた単語が候補になる
- **GIVEN** 英語モデルの準備ができている
- **WHEN** 入力欄に「apple」と書いて認識する
- **THEN** 認識候補の文字列リストが返る

### Requirement: 英語モデルを未取得のときだけダウンロードする
起動時に英語モデルが端末にあるかを確認し、ない場合だけダウンロードしなければならない（SHALL）。

#### Scenario: 初回起動
- **GIVEN** 英語モデルが端末にない
- **WHEN** アプリを起動する
- **THEN** 英語モデルのダウンロードが始まる

#### Scenario: 2回目以降の起動
- **GIVEN** 英語モデルが端末にある
- **WHEN** アプリを起動する
- **THEN** ダウンロードは行わず、すぐに判定できる状態になる

### Requirement: モデル準備中は判定できない
英語モデルの準備が終わるまでは、「判定」ボタンを無効にし、「準備中」と表示しなければならない（SHALL）。

#### Scenario: ダウンロード中
- **WHEN** 英語モデルをダウンロードしている
- **THEN** 「判定」ボタンは押せず、「準備中」と表示される

#### Scenario: ダウンロード完了
- **WHEN** 英語モデルのダウンロードが完了する
- **THEN** 「準備中」の表示が消え、「判定」ボタンが押せるようになる

### Requirement: モデルのダウンロード失敗を知らせる
英語モデルのダウンロードに失敗した場合、「準備中」の表示を消し、代わりに「判定」ボタンの上に「モデルのダウンロードに失敗しました」と表示しなければならない（SHALL）。「判定」ボタンは無効のままとする。

#### Scenario: ダウンロード失敗
- **GIVEN** 端末がオフラインで英語モデルがない
- **WHEN** アプリを起動し、ダウンロードが失敗する
- **THEN** 「準備中」は表示されず、判定ボタンの上に「モデルのダウンロードに失敗しました」と表示され、判定ボタンは押せない

### Requirement: 認識中は判定ボタンを無効にする
認識処理を実行している間は、「判定」ボタンを無効にしなければならない（SHALL）。

#### Scenario: 判定ボタンの連打を防ぐ
- **WHEN** 「判定」を押して認識処理が実行中である
- **THEN** 「判定」ボタンは押せない

### Requirement: 認識処理の失敗を知らせる
認識処理そのものが失敗した場合は、判定ボタンの上に「認識に失敗しました」と表示し、writing のままにしなければならない（SHALL）。correct や incorrect には移らない。

#### Scenario: 認識エラー
- **WHEN** 「判定」を押し、認識処理がエラーになる
- **THEN** 「認識に失敗しました」と表示され、書いた線は残ったまま writing の状態が続く

#### Scenario: 認識エラーの表示が消える
- **GIVEN** 「認識に失敗しました」と表示されている
- **WHEN** 「判定」か「消す」を押す、または別の問題に移る
- **THEN** 「認識に失敗しました」の表示が消える
